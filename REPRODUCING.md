# Reproducing the results

Every record in `reports/` and every figure in `figures/` is
generated by the code in this repository from the pinned
configurations in `configs/` and the public dataset. Training has
two sources of randomness — the initial network weights and the
order in which films are grouped into batches each epoch. Both are
fixed by the single `seed` in each config file and by nothing else,
so rerunning a configuration reproduces the trained models exactly;
on one platform the whole chain regenerates bit for bit — same
records, byte-identical figures. Across platforms, floating-point
library differences can move last digits; cross-platform
bit-identity is not guaranteed. Each record carries its own
provenance: the
configuration path, the code revision, the seeds, the package versions
and the dataset checksum.

## Setup

- Python ≥ 3.11.
- CPU-only PyTorch on Linux x86_64 or Windows:
  `pip install -r requirements-torch-cpu.txt`. On macOS and Linux ARM
  the PyPI wheels are already CPU-only and `pip install torch`
  suffices.
- `pip install -e ".[dev]"`
- Dataset download and extraction: the verified commands are in
  [data/README.md](data/README.md) — an atomic download with MD5
  verification, then one unzip into `data/raw/Dataset/`.

## The chain

Run from the repository root, in this order (later records read only
the data and the configs; the order mirrors how the project was
built):

| Step | Command | Produces | Time¹ |
|---|---|---|---|
| Quality control | `python scripts/write_qc_report.py` | `reports/curve_diagnostics.csv`, `reports/qc_summary.json` | < 1 s |
| Statistical baselines | `python scripts/run_pilot.py` | `reports/pilot_baselines.json`, 2 figures | ~ 3 s |
| Trained models | `python scripts/run_vae.py` | `reports/vae_experiments.json`, 3 figures | ~ 40 s |
| Thickness comparison | `python scripts/run_thickness.py` | `reports/thickness_experiments.json`, 3 figures | ~ 50 s |
| Seed diagnostics | `python scripts/run_seed_diagnostics.py` | `reports/seed_diagnostics.json` | ~ 30 s |

¹ Reference laptop, CPU, torch 2.x. Total: about two minutes.

The notebooks (`audit`, `baselines`, `features`) recompute the
analysis behind the written audit summary
(`reports/data_audit.md`, whose numbers the audit notebook reproduces).
Execute them in Jupyter (`pip install jupyter`):
`jupyter nbconvert --to notebook --execute --inplace notebooks/audit.ipynb`
and likewise for the other two. Generation of the json records and
figures is independent of Notebook execution.
